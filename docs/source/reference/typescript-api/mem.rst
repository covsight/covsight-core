############################
In-Memory Backend
############################

The ``mem`` module provides a fully in-memory implementation of the UCIS API.
Use it to build coverage databases programmatically without any file I/O.

.. code-block:: typescript

   import { MemUCIS } from '@covsight/core/mem';
